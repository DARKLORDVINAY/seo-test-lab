Reference

Let a label explain the destination

A link label should help a reader understand where the link leads or what information the destination provides. The surrounding sentence can supply context, but a long list of identical labels makes it harder to distinguish different destinations. Prefer wording that identifies the relevant topic or task.

Read the label before opening the destination, and write down the expectation it creates. Then inspect the destination. If a link says 'download the checklist', the reader should not arrive at an unrelated introduction with no checklist. Accurate labels reduce the effort needed to decide which path is useful.

Review repeated navigation

Shared navigation benefits from stable, recognisable labels. A page-specific contextual link can be more descriptive because it sits beside the explanation that makes the destination relevant. Both forms can be useful; neither should be added simply to meet a numerical link target.

Consider keyboard and assistive-technology use as well as visual appearance. A link must be distinguishable from ordinary text, show visible focus, and provide an accessible name. An icon without explanatory text may need an appropriate label, but avoid duplicating information in a way that makes every control unnecessarily verbose.

Preserve a clear relationship

When a destination changes, review its label as well as the URL. A working address can still mislead if the old wording promises information that is no longer present. Keep the label, surrounding explanation, and destination aligned with the task the reader is trying to complete.
