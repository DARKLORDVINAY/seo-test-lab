Guide

Write a descriptive page title

A page title helps someone recognise a destination before opening it. It also helps distinguish browser tabs after several pages are open. Start with the page's specific subject and the job it performs. A title such as 'Preparing a bicycle for winter storage' tells a reader more than 'Useful advice'.

The title should match the substance of the page. Promising a complete procedure when the body contains only a brief note creates a gap between expectation and experience. Adding popular words cannot repair that gap. First decide whether the page meets its purpose, then describe it accurately.

A small writing process

  • Write one sentence explaining the intended reader's question.
  • Underline the subject and the action the page supports.
  • Use those ideas in a natural, specific title.
  • Add a short project or organisation name only when it helps recognition.
  • Compare the result with other titles on the same site so that different pages remain distinguishable.

Check the result in context

Read the title beside the visible heading and first paragraph. They do not have to use identical words, but they should set compatible expectations. Then inspect the actual browser tab, including a narrow viewport. Display space varies, so there is no single character count that guarantees a particular appearance everywhere. Keep the important identifying words early and remove phrases that add no meaning.
